# Temporal Buildingness Model

**Temporal Buildingness Model** is a theoretical computational project that simulates how informal urban transport can behave like a mobile architectural system through repeated movement, pausing, anchoring, boarding, alighting, and street-edge interaction.


## 1. Project Premise

The central idea of this project is:

> **Informal urban transport can be understood as a form of temporal buildingness when it repeatedly performs building-like spatial behaviors over time.**

A rickshaw, e-rickshaw, tuk-tuk, or similar informal transport mode is not treated as a building because it is fixed or permanent. Instead, it is considered building-like because it can produce temporary architectural conditions such as:

- anchoring at active street edges
- waiting near pedestrian demand
- creating boarding and alighting thresholds
- carrying passengers as a temporary interior
- pausing within the street
- repeatedly occupying curbside locations
- forming rhythmic cycles of movement and temporary spatial occupation

The model tests whether these repeated behaviors can be measured computationally.
